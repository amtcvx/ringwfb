-------------------------------------------------------------------------------
This project provides wireless communication between ground / board and board / board systems.

-------------------------------------------------------------------------------
It is base on a library from OpenIPC for long-range digital video links.

"Devourer is a userspace Wi-Fi driver for Realtek's 802.11n, 802.11ac and 802.11ax USB adapters"
"It talks to the chip directly over libusb: no kernel module, no DKMS tree to patch every time 
your kernel updates, no root filesystem to taint"

-------------------------------------------------------------------------------
For Desktop (ex: GCS)  Ubuntu 24.04
For Onboard radxa zero 3W (Ubuntu 24.04 kernel 6.1.0-1027-rockchip)
